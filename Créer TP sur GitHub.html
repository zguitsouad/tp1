باش تدير les TP ديالك فـ GitHub، خاصك تدير واحد الـ repository و ترفع فيه الملفات ديالك. غادي نشرح ليك الخطوات وحدة بوحدة:

✅ 1. إنشاء حساب على GitHub (إلا ماكانش عندك)

  • سير لـ https://github.com

  • دير sign up و تبع التعليمات باش تدير compte جديد.

✅ 2. إنشاء Repository جديد

  1. من الصفحة الرئيسية ديال GitHub، كليك على الزر الأخضر "New" أو سِر مباشرةً لـ https://github.com/new

  2. عطيه اسم (مثلاً TP-SVT ولا TP-Math)

  3. ممكن تزيد Description (اختياري)

  4. خليه Public أو Private حسب رغبتك

  5. فعل خيار "Initialize this repository with a README" إلى بغيتي

  6. كليك على Create repository

✅ 3. رفع الملفات (TPs) ديالك

📌 الخيار 1: مباشرة من الموقع

  1. فـ الصفحة ديال الـ repo، كليك على "Add file" > "Upload files"

  2. جبد و حط الملفات (ولا دير "Choose your files")

  3. من بعد، كليك على "Commit changes"

📌 الخيار 2: باستعمال Git (محليًا)

  1. فتح terminal (ولا Git Bash فـ Windows)

  2. كتب هاد الأوامر:

bash
git clone https://github.com/USERNAME/NOM_DU_REPO.git
cd NOM_DU_REPO
# دير نسخ أو لصق لملفات TP هنا
git add .
git commit -m "Ajout des TPs"
git push

✅ بدل USERNAME و NOM_DU_REPO بالإسم ديالك و إسم الريبو.

🧠 نصائح إضافية:

  • قسم الـ TP حسب الموديلات ولا المواد (باستعمال dossiers)

  • دير commit message مفهوم (مثلاً: "TP sur la génétique", "Ajout TP1 Chimie")

  • كتب README.md باش تشرح شنو كاين فـ الريبو

إلا بغيتي نعاونك ندير أول TP معاك، عطيني اسم TP و الملفات اللي عندك، ونوريك خطوة بخطوة.
